# RadarTG — Система мониторинга тревог, анти-спам парсер и Telegram-бот

Полноценная система для мониторинга каналов воздушных тревог, удаления рекламы/ссылок/сборов, автоматического цитирования через Telegram Bot API и исполнения тактических сценариев.

---

## 🚀 Инструкция по запуску на вашем ПК (Windows / macOS / Linux)

### 1. Требования
- Установленный **Node.js** версии 18 или новее ([скачать с официального сайта](https://nodejs.org/)).

---

### 2. Установка и запуск (Самый простой способ для Windows)

#### Вариант А: Запуск в 1 клик (Windows)
1. Просто дважды кликните по файлу **`start.bat`** в папке проекта!
2. Скрипт сам автоматически проверит и установит все зависимости (`npm install`) и запустит сервер.
3. Откройте в браузере: **http://localhost:3000**

#### Вариант Б: Запуск через командную строку
1. Откройте терминал (PowerShell / CMD / Terminal) в папке проекта:
   ```bash
   npm install
   ```
2. Запустите сервер:
   ```bash
   npm run dev
   ```
3. Откройте в браузере: **[http://localhost:3000](http://localhost:3000)**

---

## 💾 Локальная база данных и резервное копирование

- **Автоматическое сохранение:** Все данные (перехваченные сообщения, тактические задачи, логи, стоп-слова, regex-правила и настройки Telegram-бота) автоматически сохраняются на локальный диск в файл:
  `data/radar_database.json`
- **Скачивание базы (Бэкап):** В шапке сайта нажмите кнопку **«База & ПК»** ➔ **«Скачать полную базу (.json)»**.
- **Восстановление / Импорт:** В том же окне выберите сохраненный `.json` файл, чтобы мгновенно загрузить все данные на новом ПК.

---

## 🤖 Как настроить Telegram Бота для авто-публикации

1. Создайте бота через `@BotFather` в Telegram и скопируйте его токен.
2. Создайте канал или группу, добавьте туда созданного бота в качестве **Администратора** с правом публикации сообщений.
3. В веб-интерфейсе перейдите во вкладку **«Telegram бот»**, введите токен и `@username_канала`.
4. Нажмите **«Проверить токен»** и отправьте тестовое сообщение.
